# Quack!
quack quac QUAK aCK, quackk Quack qquack.. QUACK uack!!...

## Building
```
npm install
node build.mjs
```

## How to use it
Click to Quack!

## How it works
I used some divs and css to make the cute duck, and a "pointerdown" event listener to make the duck and the background color bounce, as well as play the quack sound! The Web Audio API is so abstracted and the quack sound is kinda bad tbh :/
